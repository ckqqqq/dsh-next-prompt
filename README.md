# dsh-next-prompt

DSH 的本地自适应下一提示插件。它从本会话实际发生的“上一条用户提示 + 助手最终回答 → 下一条用户提示”学习，展示一个候选，按 **Tab** 填入输入框，**Esc** 忽略。按 Enter 发送仍由用户操作。

这是可安装的 0.1.0 实现，本地在线检索排序可以直接工作；另外提供可选的模型预测，把已学习的相关示例交给 DSH 默认模型，用于推测尚未出现过的下一提示。它不会训练神经网络，也不是 Cursor 的模型或实现复刻。模型预测默认关闭，勾选后才会发送上下文并产生模型用量。

## 安装

匹配并验证的 DSH 版本：**0.2.0-rc.2**，Web 客户端；Node.js >= 22。DSH 正在快速变化，peer 版本明确锁定，升级需重新验证。

```powershell
cd D:\0_Coding\0_for_Deepseek\dsh-next-prompt
npm ci --ignore-scripts
npm run check
npm pack
# 将产物加入 web profile，然后重启该 profile：
dsh plugin --profile web add D:\0_Coding\0_for_Deepseek\dsh-next-prompt\dsh-next-prompt-0.1.0.tgz
dsh web
```

安装会更改指定 profile。以上命令供用户使用；本项目开发仅启动独立的 smoke profile，没有安装到你的日常 web/desktop profile。不要将 npm CLI 的 web 安装视为已完成桌面安装：桌面使用自己的运行时和 profile，需在其插件管理界面选择本地包，且版本必须匹配。TUI/headless 没有此输入 UI。

移除：`dsh plugin --profile web remove dsh-next-prompt`。卸载包不清除浏览器 localStorage；先在插件里点击“关闭并清除”。

## 使用

1. 打开一个会话，在输入框上方点击“开启本会话学习”。默认关闭。
2. 正常工作。只学习开启后追加的、已持久化的人工消息。首次打开的历史、向上翻页、助手猜测、自动化消息不训练。
3. 出现过的下一提示可以按精确前缀补全，至少输入两个字符。空输入时，至少两条匹配训练记录且上下文相似才会展示预测；没有足够证据时保持安静。
4. Tab 接受，Esc 忽略，或者点击候选接受；用户随后决定是否发送。忽略会降低该候选排序。接受本身不会把未发送文本加入训练集。
5. “关闭并清除”停止学习并删除本会话模型。存储不可用时明确显示“仅保留在内存”。
6. 需要推测新的提示时，可勾选“模型预测（发送上下文）”。它通过 DSH 的已认证连接调用宿主默认模型；凭据仍由 DSH 管理。模型失败时保留本地建议，原始错误不会暴露到界面。

预测同时以候选条和灰色文字预览呈现。灰色预览使用独立、不可交互的文本层，未接受的内容不会进入编辑器文档或提交。只在普通纯文本草稿、无附件/引用芯片、光标位于末尾且没有选区时接受。Shift+Tab 保持焦点移动；中文输入法、DSH 自带 `/`/`@` 菜单优先。新输入导致旧建议失效时，不插入任何内容。

## 学习、隐私与边界

- 数据按 **浏览器 origin + 会话 ID** 隔离。不会自动跨项目、跨会话收集个人习惯；这也意味着每个新会话需要积累样本。
- 开启学习后，原始训练提示和截取的上下文以 **明文 localStorage** 保存。本地检索不调用模型；启用模型预测后，当前上下文、草稿和最多 5 个相关学习示例会通过 DSH 发送给模型提供方。同源脚本可以访问本地数据。
- 最多 256 条训练记录，提示最长 800 UTF-16 单元，上下文最长 1600；30 天过期在模型访问时惰性清除。未再次打开的会话数据不会由后台定时物理删除，清除站点数据可一次删除全部记录。
- 明显的密钥、密码赋值、邮箱及身份证形态会让整条记录被排除，私密记录会切断学习链；过滤是启发式，无法识别所有个人或机密信息。
- 一次只展示一个候选，排序分值是相似度、时效与反馈权重，**不是校准后的正确概率**。不会执行建议，不添加 agent 工具，不注入 system prompt。
- 多窗口同会话会同步外部清除；同时写入仍是 localStorage 的最后写入者获胜，可能丢失少量训练记录。生产级跨设备学习需要另外设计事务存储及用户授权。
- 模型预测在停顿后触发，先使用已有本地建议；每会话每分钟最多 8 次请求、宿主最多 24 次，宿主同时最多 2 次。更改草稿会取消旧请求，单次请求限时 7 秒，错误后客户端冷却 30 秒。生成的文字只有实际发送后才可能进入训练。

## 验证

```powershell
npm run check       # 严格类型检查 + 单元/DOM测试 + 构建
npm run benchmark   # 先预测后学习的合成基准
node scripts/smoke.mjs # 隔离 DSH_HOME 下真实启动 Web，不调用模型
```

测试覆盖冷启动拒答、中文检索、前缀保持、反馈、容量/过期、敏感过滤、损坏存储、历史去重、输入法、菜单冲突、草稿版本保护、仅插入不提交及卸载清理，另验证生成协议、取消/缓存/限流、模型路由和错误脱敏。构建依赖 externalize，客户端使用 DSH 提供的 React/Cordis，不捆绑第二份 React。模型测试使用受控流，不把模拟结果当成真实提供方准确率或真实 API 验证。

合成重复工作流只证明可学习性、拒答行为和执行速度，不能推断真实用户准确率。真实评估应先预测后记录实际下一提示，报告 Top-1/Top-3、覆盖率、接受率、编辑距离和端到端延迟，按时间划分训练/验证，避免把下一提示提前输入模型。

具体设计和验收状态见 [docs/design.md](docs/design.md)。上游接口参照 [DSH 官方仓库](https://github.com/deepseek-ai/deepseek-harness)，本地构建直接使用 0.2.0-rc.2 的公开类型。
