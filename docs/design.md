# 设计与验收

## 目标与交互不变量

预测的是用户下一条消息或正在输入消息的后缀。建议不能触发发送、执行代码或修改会话历史。插入必须验证会话归属、当前草稿版本、完整前缀、末尾空选区和输入阶段；DSH 的 insertText(span) 再做版本比较。用户接受预测后仍可以编辑、撤销或不发送。

## 数据通路

```text
SessionBinding.eventSource
  ├─ replace: 只恢复当前上下文、水位
  ├─ prepend / transient: 不训练、不倒退上下文
  └─ append: seq 去重 → 人工来源验证 → 私密过滤 → 训练样本
      └─ 已发送上一提示 + 最终助手文本 → 已发送下一提示

当前上下文 + 草稿前缀
  → 字词/汉字及相邻二元组集合
  → 余弦式集合相似度
  → 时效衰减 + 接受/忽略反馈
  → 阈值、证据数量、精确前缀过滤
  → 候选条 → 用户 Tab → DSH 公开 insertText
```

engine 不依赖 DSH、DOM、网络；learning 负责事件来源及水位；storage 负责版本化持久化及拒绝损坏数据；runtime 绑定 retained session 生命周期；client 注册官方 slot；Suggestion 负责显示和交互；Ghost 使用单独的文本层镜像排版，不修改编辑器文档。

本地单次检索 O(N×L)，N<=256、L<=1600，没有向量数据库、远程 embedding 或模型权重更新。可选模型预测通过 DSH Connection 的共享已认证 RPC 通道进入 host，再调用配置的 DSH LLM 提供方，不另起服务器、不收集新的 API Key。默认使用宿主默认模型；provider/model 可在插件配置中成对覆盖。生成请求没有工具，也不写入主聊天输入或自动发送建议。

generation 验证有界 JSON、排除敏感内容和命令、要求精确前缀；GenerationCoordinator 提供最新请求优先、取消、16 项缓存、每分钟 8 次请求和失败冷却。宿主限制同时 2 次、每分钟 24 次以及 7 秒期限。历史生成结果不会直接训练模型。跨会话个人模型和跨设备同步仍未实现。

## 生命周期和异常

- 每个 SessionBinding 只有一个 runtime；slot 重绘不重复订阅。
- session 释放或插件卸载，均移除事件和 storage 订阅；dispose 幂等。
- 开启前不训练、不落盘；关闭清除模型。模型可只在内存工作，并展示持久化错误。
- 接受/忽略反馈只影响排序；下一次 durable 人工消息才生成新训练记录，避免自我训练回路。
- 页面刷新重建上下文；基线不重复训练。缺失/损坏/未来版本持久化数据不会部分加载。
- 同会话跨窗口清除触发 storage 事件，其他窗口重载状态；并发记录可能最后写入覆盖，不承诺事务一致性。
- 当前会话文本替换事件切断上下文，不回滚此前已经学习的旧样本；需要删除训练内容时使用“关闭并清除”。

## 验收层级

| 层级 | 手段 | 可以证明 |
|---|---|---|
| 类型契约 | tsc，DSH 0.2.0-rc.2 发布包 | 公开 API 调用形状匹配 |
| 学习语义 | node:test | 水位、排除规则、在线更新、阈值、反馈、持久化 |
| DOM 交互 | React + jsdom | Tab/IME/菜单优先、过期草稿、无发送、卸载监听 |
| 模型边界 | 受控 DSH 流和取消测试 | JSON 校验、路由、前缀、旧请求隔离、限流及错误脱敏；不证明真实提供方效果 |
| 安装与宿主 | 独立 DSH_HOME + composition + Web HTTP | 宿主启动、包发现和客户端 roster |
| 实机桌面 | 尚未执行 | 不能声称完成 Electron UI、真实 IME和视觉验收 |
| 预测效果 | 合成 prequential benchmark | 重复模式可学习及检索时延，不能证明真实准确率 |

下一阶段真实验收应使用明确授权的非敏感会话数据进行时间外推，记录建议展示前的实际上下文。不要导入当前简历目录或扫描用户其他 DSH 历史。
